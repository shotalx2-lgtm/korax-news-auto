# KORAX NEWS Auto Publisher

بوت ينشر أخبار كرة القدم الجديدة تلقائيًا في قناة Telegram من مصادر RSS.

## إعداد Telegram

1. أنشئ بوتًا عبر BotFather وأضفه مشرفًا في القناة مع صلاحية نشر الرسائل والصور.
2. من المستودع افتح Settings → Secrets and variables → Actions.
3. أضف Repository secret باسم `TELEGRAM_BOT_TOKEN` وضع رمز البوت الجديد.
4. أضف Repository variable باسم `TELEGRAM_CHAT_ID` وقيمته `@KoraxNews11`.

لا تضع رمز البوت في الملفات أو في المحادثات. إذا سبق مشاركة رمز قديم، ألغِه من BotFather وأنشئ رمزًا جديدًا.

## التشغيل

من تبويب Actions اختر **KORAX NEWS Auto Publisher** ثم **Run workflow** لتجربة التشغيل يدويًا. بعد ذلك تعمل الجدولة تلقائيًا.

## ملاحظات مهمة

- GitHub Actions لا يتيح جدولة كل دقيقة؛ الجدولة هنا كل 5 دقائق، وقد تتأخر أكثر حسب ضغط GitHub.
- RSS لا يرسل إشعارًا لحظيًا؛ البوت يكتشف الخبر عند الفحص التالي.
- تتم محاولة ترجمة العنوان والملخص إلى العربية عبر خدمة ترجمة عامة دون مفتاح API. هذه الخدمة غير مضمونة وقد تتوقف أو تعيد النص الأصلي عند تعذر الترجمة.
- صورة الخبر تُنشر إذا وفرها RSS وكان Telegram قادرًا على الوصول إليها.
- لا ينشر البوت نص المقال كاملًا؛ يكتفي بعنوان وملخص ورابط المصدر.
- يحتفظ الملف `seen_news.json` بمعرّفات الأخبار المنشورة لتقليل التكرار.
