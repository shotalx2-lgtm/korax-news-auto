# KORAX NEWS Auto Publisher

بوت أخبار متخصص في **كرة القدم للرجال فقط**، ينشر إلى قناة Telegram بتصميم أسود AMOLED ولمسات أخضر ليموني، مع عنوان عربي وصورة خبر كبيرة قدر الإمكان.

## نطاق التغطية

- أخبار عالمية وعربية من كووورة وBBC وSky Sports وThe Guardian وThe Athletic.
- متابعة أوسع للدوريات الأوروبية، البطولات القارية والعالمية، مسابقات الأندية، المنتخبات، الانتقالات واللاعبين عبر خلاصات بحث Google News.
- تغطية عربية ومصرية من كووورة واليوم السابع وخلاصات الأخبار العربية.
- استبعاد أخبار كرة القدم النسائية وباقي الرياضات، مع فلترة المحتوى الترويجي والتكرار.

## إعداد Telegram

1. أضف البوت مشرفًا في القناة مع صلاحية نشر الرسائل والصور.
2. من Settings → Secrets and variables → Actions أضف:
   - Secret باسم `TELEGRAM_BOT_TOKEN`.
   - Variable باسم `TELEGRAM_CHAT_ID` وقيمته `@KoraxNews11`.
3. لا تضع رمز البوت في الملفات أو المحادثات. ألغِ أي رمز سبق تسريبه.

## الترجمة العربية

- يحاول البوت استخدام Microsoft Translator عند توفير `AZURE_TRANSLATOR_KEY` و`AZURE_TRANSLATOR_REGION` كـ Secrets.
- من دون المفتاح يستخدم MyMemory كخيار مجاني محدود؛ يمكن إضافة `MYMEMORY_EMAIL` كـ Secret لزيادة الحصة المجانية وفق شروط الخدمة.
- **لا ينشر البوت عنوانًا إنجليزيًا عند فشل الترجمة**؛ يؤجل الخبر بدل نشره بلغة غير مطلوبة.
- يمكن إضافة مفتاح Microsoft Translator من Azure لاحقًا لضمان ترجمة أكثر ثباتًا، مع مراعاة حصة الخطة.

## الصور والمنشورات

- يختار البوت أكبر صورة متاحة من بيانات RSS، ثم يحاول استخراج صورة المقال الأصلية من Open Graph.
- يرفض الصور الصغيرة جدًا حتى لا ينشر صورة مشوشة؛ عند عدم توفر صورة مناسبة يستخدم بطاقة KORAX نظيفة بدل صورة منخفضة الجودة.
- بطاقة الخبر 1200×675، بخط عربي واتجاه كتابة RTL، مع صورة الخبر وعنوانه وتصنيف المسابقة.
- نص المنشور يحتوي العنوان والملخص العربي عندما يتوفر، والتصنيف والمصدر ورابط المقال الأصلي.
- لا يعيد نشر المقال كاملًا؛ يحافظ على رابط المصدر.

## التشغيل والحدود

- الجدولة كل 5 دقائق عبر GitHub Actions، ويمكن التشغيل يدويًا من تبويب Actions.
- ينشر البوت حتى 5 أخبار في كل تشغيل لتجنب إغراق القناة.
- هذه شبكة مصادر عامة واسعة وليست ضمانًا لتغطية كل خبر في كل دوري أو نادٍ في العالم؛ التغطية تعتمد على ما تنشره الخلاصات ومصادر البحث.
- قد تتأخر بعض الأخبار حسب تحديث RSS ووقت تشغيل GitHub Actions.
- يحتفظ `seen_news.json` بمعرّفات الأخبار لتقليل التكرار.
