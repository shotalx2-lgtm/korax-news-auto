# KORAX NEWS & MATCH CENTER

بوت تيليجرام لأخبار كرة القدم للرجال ومواعيد المباريات. التصميم الجديد يعتمد الأزرق الملكي المتدرّج مع الأبيض والسماوي؛ تم إلغاء خلفية AMOLED السوداء والأخضر الليموني من بطاقات الأخبار والمباريات.

## الأخبار

- أخبار عربية وعالمية من كووورة وBBC وSky Sports وThe Athletic واليوم السابع ومصادر كرة قدم أخرى موضحة في sources.json.
- فلترة لاستبعاد أخبار السيدات والرياضات الأخرى وتقليل تكرار العناوين.
- عنوان عربي وملخص عربي عند توافر الترجمة، مع رابط المقال الأصلي.
- صورة المقال الأصلية عند توافر صورة مناسبة، وإلا بطاقة خبر بهوية KORAX الزرقاء.
- لا يعيد البوت نشر المقال كاملًا.

## مركز المباريات

ملف fixtures.py مستقل عن ناشر الأخبار، ويُشغّل كل 30 دقيقة. يبحث عن المباريات القادمة خلال 24 ساعة وينشر حتى 3 بطاقات في التشغيل الواحد، مع حفظ المعرّفات المنشورة لمنع التكرار.

### مصدر البيانات

- يستخدم ESPN Soccer Site API العامة عبر site.api.espn.com، ولا تحتاج إلى API key أو تسجيل دخول لطلبات القراءة العامة.
- بيانات المباراة تشمل وقت البداية، الفريقين، شعاري الناديين متى وفرهما المصدر، اسم المسابقة، المرحلة/الجولة عند توافرها، الملعب، وسجل آخر المباريات عند توافره.
- يُحوَّل الموعد إلى توقيت القاهرة Africa/Cairo قبل عرضه.
- قائمة البطولات والدوريات في fixtures.json: الإنجليزي والإسباني والإيطالي والفرنسي والألماني والبرازيلي والأمريكي والسعودي، وكؤوس محلية، ودوري أبطال أوروبا والدوري الأوروبي ودوري المؤتمر، وأمم أوروبا وتصفياتها، وأمم إفريقيا وتصفياتها ودوري أبطال إفريقيا، وكأس العالم وتصفياته، وكوبا أمريكا وليبرتادوريس، وبطولات آسيا والكونكاكاف.
- المصدر لا يوفّر تغطية مؤكدة لكل دوري في كل دولة. لم أجد حتى الآن endpoint عامًا موثقًا بلا مفتاح للدوري المصري الممتاز ضمن المصدر المختار، لذلك لا يضيف البوت مباريات مصرية تخمينية. أضف مصدرًا موثوقًا لاحقًا عند التحقق منه.
- لا تظهر مرحلة أو جولة أو ملعب أو شعار إذا لم يرسل المصدر هذه البيانات؛ لا يتم تخمين بيانات ناقصة.
- قد تتغير مواعيد المباريات من الجهة المنظمة، ولذلك يعيد البوت فحص الجداول دوريًا.

## التصميم

- مقاس صور الأخبار والمباريات 1200×675.
- هوية زرقاء ملكية مع سماوي وأبيض، من دون الأسود AMOLED أو الأخضر الليموني.
- بطاقة المباراة تعرض الشعارين، اسمي الفريقين، تاريخ المباراة، توقيت القاهرة، البطولة، والمرحلة/الملعب عند توفرهما.
- نص تيليجرام يضيف وصفًا للمواجهة ورابط صفحة تفاصيل المصدر.

## إعداد Telegram

في GitHub → Settings → Secrets and variables → Actions:

- Secret: TELEGRAM_BOT_TOKEN
- Variable: TELEGRAM_CHAT_ID = @KoraxNews11

أضف البوت مشرفًا في القناة مع صلاحية نشر الصور والرسائل. لا تضع رمز البوت داخل الملفات أو المحادثات.

## الاختبارات والتشغيل

- الأخبار: publish-news.yml، كل 5 دقائق.
- المباريات: publish-fixtures.yml، كل 30 دقيقة.
- تحقق محلي: python -m py_compile bot.py fixtures.py
- اختبارات تحليل بيانات المباريات: python -m unittest -v test_fixtures.py
- ملفا seen_news.json وseen_matches.json يحفظان منع التكرار.
- يستخدم مسارا التشغيل مجموعة concurrency واحدة حتى لا يتعارض حفظ حالة الأخبار مع حفظ حالة المباريات.
